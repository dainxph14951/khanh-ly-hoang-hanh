# Thiệp Khánh Ly & Hoàng Hanh

Thiệp mới tông đỏ rượu vang, nền giấy kem, hoa nét mảnh. Có modal mở thiệp với hai cánh trượt sang hai bên và chữ hiện dần theo từng phần khi cuộn. Hiệu ứng được giảm khi thiết bị bật chế độ giảm chuyển động. Dùng lại font có sẵn từ `duc-huyen-wedding`. Nội dung theo hai ảnh thiệp giấy; không cần cài thư viện, không phụ thuộc API hoặc CDN.

## Xem thiệp

Mở trực tiếp `dist/index.html` hoặc chạy:

```sh
cd khanh-ly-hoang-hanh-wedding
npm start
```

Địa chỉ: http://127.0.0.1:8012. Đổi cổng bằng `PORT=8013 npm start`.

Có thể tạo lời mời theo khách bằng `/?guest=Anh%20Nam`. Mặc định: “Mời các bạn 12D khóa 94-97”.

## Chỉnh sửa và phát hành

- Nội dung: `dist/index.html`.
- Giao diện: `dist/style.css`.
- Tên khách từ đường dẫn: `dist/invitation.js`.
- Font và hoa SVG: `dist/assets/`.
- Kiểm tra: `npm run check` hoặc `npm run build`.
- Đưa toàn bộ thư mục `dist` lên hosting tĩnh để phát hành; không cần bước biên dịch.
